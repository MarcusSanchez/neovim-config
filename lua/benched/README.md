# Benched plugin specs

Experiments that were tried and shelved, kept as real lazy.nvim specs so
they're one `mv` away from coming back. `lua/benched/` is not imported by
lazy.nvim — to revive one, move its file into `lua/plugins/` and follow the
notes at the top of the file.

- `harpoon.lua` — harpoon2 quick-jump slots (`,ha` / `,hl` / `,1`–`,9`),
  benched 2026-08-13 in favour of bufferline tabs.
- `oil.lua` — buffer-as-filesystem explorer in a float (`-` / `,a`),
  benched 2026-08-13 in favour of the snacks explorer sidebar.
